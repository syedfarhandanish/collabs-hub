> **The unified command center and central gateway for the Collabs EdTech ecosystem.**

**Collabs Hub** is the central landing page connecting students, mentors, and educators to our complete suite of digital tools. Designed for speed, simplicity, and seamless navigation, this hub brings all Collabs web applications together under one unified interface.

---

## 🔗 Live Deployment
**https://www.collabs.eu.org/**

## 📂 The Collabs Ecosystem
This hub provides direct, centralized routing to our core applications:
* **Collabs Scholar:** An open-access digital research library.
* **eAttendance System:** Institutional attendance tracking for Class A and B.
* **e-Voting Portal:** Secure digital elections for student councils.
* **Registrations Portal:** Centralized onboarding for students, alumni, and mentors.
